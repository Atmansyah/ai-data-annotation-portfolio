
# Parking Lot Detection Annotation

## Project Overview

This project involved 3D bounding box annotation for parking lot detection tasks.

The objective was to identify and annotate parking spaces and relevant objects in 3D scenes according to project-specific guidelines.

## Tasks Performed

- Created 3D bounding boxes around relevant objects.
- Identified parking spaces within the designated region of interest (ROI).
- Annotated occupied and unoccupied parking spaces.
- Adjusted bounding box dimensions and positioning based on annotation guidelines.
- Reviewed annotations and performed corrections based on quality feedback.
