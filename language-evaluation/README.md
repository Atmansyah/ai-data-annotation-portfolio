# Language Evaluation

## Project Overview

This section showcases experience in Indonesian language-related AI tasks, including language assessment, text quality review, and evaluation of AI-generated content based on task-specific guidelines.

## Evaluation Activities

- Indonesian text evaluation
- Language quality assessment
- Grammar and spelling review
- Text relevance assessment
- Instruction compliance evaluation
- AI-generated language output review

## Evaluation Criteria

- Grammatical accuracy
- Natural language usage
- Contextual relevance
- Clarity and readability
- Instruction compliance

## Objective

To support the development of high-quality multilingual AI systems by assessing language accuracy, naturalness, and content quality.
