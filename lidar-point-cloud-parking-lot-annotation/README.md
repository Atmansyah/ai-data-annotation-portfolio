
# LiDAR Point Cloud – Parking Lot Annotation

## Project Overview

This project involved annotating LiDAR point cloud data for parking lot detection.

The objective was to identify and analyze parking spaces and relevant objects in 3D point cloud scenes based on project-specific annotation guidelines.

## Tasks Performed

- Created 3D bounding boxes around relevant objects.
- Identified parking spaces within the designated region of interest (ROI).
- Annotated occupied and unoccupied parking spaces.
- Adjusted bounding box dimensions and positioning based on annotation guidelines.
- Reviewed annotations and performed corrections based on quality feedback.

- 3D Bounding Box Annotation

- Parking Lot Annotation
