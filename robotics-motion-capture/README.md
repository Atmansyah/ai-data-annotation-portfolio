# Robotics Motion Capture

## Project Overview

This project showcases my experience in robotics motion capture annotation, focusing on describing human skeletal movements based on motion capture recordings.

## Annotation Tasks

- Walking and movement description
- Step counting
- Body positioning and posture
- Arm and leg movement description
- Movement direction
- Rotational movement and turning
- Sequential motion description

## Sample Motion Description

**Example:**

"The person walks four steps forward with both arms hanging naturally at their sides, then turns approximately 50 degrees counterclockwise."
